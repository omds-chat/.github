## 组织原则

- **项目自治:** 各仓库的技术决定由其维护者负责,组织提供的是发现与协作的空间。
- **作者所有:** 代码、文档与设计的权利属于各自的开发者或权利人,组织不因收录而获得这些权利。
- **收录不等于认证:** 收录与托管只说明可被找到,不构成安全、兼容或持续维护的保证,请自行核对来源与风险。
- **开放参与:** 参与不需要组织成员身份;权限随明确的责任授予,不随热情授予。
- **轻量治理:** 常规协作直接推进,影响面大的改动保留审阅、记录与撤回的余地。
